# Breviary Latin→中文 LOCKED Glossary (Catholic / 思高 paradigm)

Authoritative term-lock for translating the Roman Breviary (Divine Office, 1960)
from **Latin** into Chinese, in a **uniform official Catholic style** (Vatican.va /
Vatican News 中文 / 《天主教教理》 / 思高圣经 register). Every Latin
term/name/formula below is rendered **exactly** as given, so the same word is
identical across all chunks. This file overrides individual translator judgment —
but never the absolute rules (God = 天主, Allelúia = 阿肋路亚, Bible names per
思高). Read together with `robo-hieronymus prompt ALT.md`.

Paradigm reminder: **Catholic / 思高 throughout.** God = 天主 (NEVER 神, NEVER
上帝). Holy Spirit = 圣神 (NEVER 圣灵). Apostle = 宗徒 (NEVER 使徒). grace = 恩宠.
faith/hope/charity (virtues) = 信德/望德/爱德. **All Bible figures, book names, and
abbreviations = 思高/Catholic.** **Church Fathers/saints = established Catholic
renderings.** This is the Catholic counterpart of `zh/glossary.md`; same sections,
same locked items, re-rendered in Catholic terminology.

## 10. Resolved decisions (Catholic paradigm — LOCK)

Apply verbatim everywhere.

1. **God** → **天主** everywhere (NEVER 神, NEVER 上主 as a *name* for Deus; 上主 is
   reserved for `Dóminus` where "the LORD/YHWH" is meant — see #11). **Holy Spirit**
   → **圣神**. **Apostle** → **宗徒**. **grace** → **恩宠**.
2. **John Chrysostom (Ioánnes Chrysóstomus)** → **金口若望**.
3. **Gregory the Great (Gregórius Papæ)** → **额我略** (教宗). St. Gregory the Great
   = **大圣额我略**.
4. **Leo the Great (Leo Papæ)** → **良** (教宗). St. Leo the Great = **大圣良**.
5. **Mother of God (Dei Génetrix / Deípara)** → **天主之母** (consistent with
   God=天主). Where the Latin is just `Mater`/`Genitrix` meaning "the Blessed
   Mother" (not the formal title), **圣母** is acceptable. B. Virgo María =
   荣福童贞玛利亚 / 圣母玛利亚.
6. **Church Father renderings** — LOCK as (Catholic forms): Augustine=奥斯定,
   Jerome=热罗尼莫, Ambrose=安博, Athanasius=亚大纳削, Cyril=济利禄,
   John Chrysostom=金口若望, Basil=巴西略, Bede=比德, Bernard=伯尔纳铎,
   Hilary=依拉略, Gregory Nazianzen=纳齐安的额我略.
7. **Eve** → name = **厄娃**. In hymns with the Áve/Éva (Ave/Eva) wordplay the pun
   is untranslatable — render the sense and note it in `_notes`.
8. **Nebuchadnezzar (Nabuchodónosor)** → **拿步高** (思高) everywhere.
9. **Confessor** (saint-category, non-martyr; and homily/title sense) →
   **精修圣人** (Catholic standard). So `Confessor Pontifex` = 精修圣人主教;
   `Commune Confessoris non pontificis` = 非主教精修圣人共通经文; etc.
10. **"feria" weekday naming** → **周一/周二/…/周六** (Feria II=周一 … Sabbato=周六),
    Dominica=主日.
11. **Dóminus** → **主** in liturgical address (Dóminus vobíscum 愿主与你们同在);
    use **上主** where it renders YHWH "the LORD" in psalm/biblical text, per 思高
    usage. **Deus** is always **天主**, never 上主.
12. Minor martyrologium toponyms (Bríxiæ, Picéno, Túscia, Wandálica, Saracénis,
    Turcárum, etc.) — translators render with standard Chinese case-by-case and
    flag obscure ones in `_notes`; not individually locked here.
